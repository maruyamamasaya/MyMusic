# MyMusic

個人利用を目的とした、iPhone向けのローカル音楽プレイヤーです。

音源を不要に変換せず、手元の音楽ライブラリをシンプルに探して再生できることを大切にしています。

## 現在の位置づけ

**完成基準版（Baseline） — 2026-08-14**

ここまでに実装した基本機能とUIを、今後の開発で維持する基準版とします。
これはApp Store向けの正式リリースを意味するものではなく、MyMusicの基本体験が一通り成立した時点のスナップショットです。

次の開発フェーズでは、この基準版を壊さないようにしながら、MyMusic独自の機能をベータ版として段階的に追加します。

## 基準版に含まれる機能

### ライブラリ

- Files／iCloud Driveからの音楽フォルダ登録
- 複数フォルダの読み込みと再読み込み
- 曲、アルバム、アーティスト、ジャンル、作曲者別の表示
- アートワーク表示とテキスト表示の切り替え
- 大規模な曲一覧に向けた非同期ソートと段階表示
- ジャンルごとの表示切り替えとチューニングプリセット

### 再生

- ローカル音源の再生、一時停止、前後の曲への移動、シーク
- 再生キュー、シャッフル、リピート
- ミニプレイヤーと再生中画面
- 再生中画面からアルバム／アーティスト詳細への移動
- 長い曲名、アーティスト名、アルバム名の1行スクロール表示
- オーディオ情報と簡易スペクトラム表示
- 再生履歴、再生回数、再生傾向の記録
- ロック画面／Control Centerの再生情報とリモート操作

### お気に入りとプレイリスト

- 曲のお気に入り
- アルバム／アーティストのお気に入り
- お気に入り一覧からの再生、シャッフル、詳細表示
- プレイリストの作成、編集、削除
- 曲の追加と検索結果からのプレイリスト作成

### 検索

- 曲名、アルバム名、アーティスト名を対象にした検索
- 検索対象に応じた曲／アルバム／アーティストの結果表示
- 複数キーワードのAND／OR検索
- ジャンル、お気に入り、評価、再生回数などの複合条件
- アーティスト名／アルバム名の部分一致、完全一致、除外条件

### ホームとデータ

- クイック再生、未発見再生、リピート曲再生
- お気に入りの曲／アルバム／アーティストからの直接再生
- 最近のプレイリスト、チューニング、ライブラリへのショートカット
- 再生分析と履歴カレンダー
- 音楽関連データのインポート／エクスポート

## 次のフェーズ：Original Features Beta

今後の新機能は、まずベータ機能として小さく追加します。

- 一度に大規模な変更をせず、1機能ずつ実装・ビルド・確認する
- 基準版のライブラリ、検索、再生、プレイリストを壊さない
- ベータ機能は目的、操作方法、既知の制限を記録する
- 十分に安定した機能だけを基準版へ昇格する
- ストリーミングやサーバー連携は、明示的に着手するまで将来機能として扱う

ベータ機能の内容が決まったら、このREADMEに「Beta Features」セクションを追加して管理します。

## Beta Features

### 音量ノーマライズ — 2026-08-29

Macで解析した曲全体のラウドネス情報を使い、明らかに小さい／大きい曲だけを再生時に控えめに補正します。

- 音源ファイルは変更せず、iPhone上で音量解析もしない
- Mac AnalyzerがIntegrated LUFS、True Peak、固定の推奨ゲインを特徴量JSONへ保存
- -17〜-11 LUFSは0 dBのまま、補正は最大±4 dB、増幅は-1 dBTPを超えない範囲に制限
- 「設定」→「オーディオ」→「音量ノーマライズ」で切り替え、初期値はOFF
- 情報がない旧データは0 dBとして従来どおり再生
- コンプレッサー、リミッター、曲中の動的な音量追従は行わない

既知の制限：True Peak ceilingは元音源と固定ノーマライズゲインに対するもので、ユーザーのEQブースト後のピークまでは保証しません。実音源・実機での聴感確認は別途必要です。

### Track Adjustments — 2026-08-29

通常の再生中画面でアートワーク領域をタップすると、アートワーク、既存のオーディオ情報、曲別調整の順に切り替わります。

- 現在位置と前回位置を確認し、前回位置へ任意に移動できる
- 共通の「1秒戻る」で現在位置を微調整してから、曲ごとの開始位置／終了位置として登録・リセットできる
- 開始位置／終了位置の登録成功時は、設定ボタンが短く光って「設定しました」と表示する
- 開始位置は次回の通常再生開始に使い、終了位置では既存のrepeat／次曲処理へ進む
- Mac解析のLUFS、True Peak、自動補正値とノーマライズON/OFFを確認できる
- 自動補正の後へ曲ごとに-2〜+2 dB、0.5 dB刻みの手動微調整を保存できる
- 最終補正は±4 dBと-1 dBTP ceilingを守り、設定OFF時は自動・手動とも音声へ適用しない
- 曲別設定はStable Track IDに紐づく端末内データで、Mac解析JSONや音源ファイルは変更しない

既知の制限：手動音量微調整は曲中で動的に変えず、次回の曲開始時から適用します。開始／終了境界とbackground保存は実機・実音源での追加確認が必要です。

### 1曲ごとの再生履歴リセット — 2026-08-29

寝落ち中のリピートなどで偏った記録を、ライブラリ全体に影響させず1曲ずつ整えるためのベータ機能です。

- 「設定」→「分析」→「よく再生している曲」で、対象の曲を長押し
- 「再生回数をリセット」を選び、確認アラートで「リセット」を実行
- 選んだ1曲の再生回数、再生日時履歴、最終再生日時だけを削除
- お気に入り、再生傾向評価、飽きた曲／シャッフル除外設定は保持

既知の制限：削除は取り消せません。全曲一括リセットは実装していません。

### ハイライト再生 — 2026-08-22

ライブラリ内の曲を約30秒ずつ縦スワイプで試聴し、知らない曲や聴き直したい曲をテンポよく見つけるためのベータ機能です。

- 5つ目の「ハイライト」タブから、セーフエリア内に固定した1画面単位の縦ページングUIで再生
- RMS、ピーク、帯域変化、低域比、音密度、直前区間からの変化、曲中位置を使って最大5候補をスコアリング
- 解析用音声はモノラル／12kHz PCMとし、元音源の再生データは変更しない
- 解析結果は音源サイズ・更新日時・解析バージョンとともにJSONキャッシュへ保存
- 未解析時や解析失敗時は曲中位置から作るフォールバック候補ですぐに再生
- 全曲一括解析は行わず、現在曲と次の5曲だけをバックグラウンドで先読み
- 約30秒後の自動送り、上下スワイプ、「別の部分」、ジャンル変更、再シャッフルに対応
- ジャケットのタップで再生／一時停止し、「グッド」「よくないね」で再生傾向を調整
- ハイライトからプレイリスト編集を開いても現在の曲は継続再生し、編集中に区間の終端へ達した場合は次の曲へ移らず停止
- 15秒聴くと再生回数へ加算し、既存のお気に入り、プレイリスト、曲情報と同じデータを利用
- 「フルで再生」ではハイライトを終了し、同じ曲の先頭から通常プレイヤーへ移行
- ハイライトから開いた通常プレイヤーを閉じるとホームへ戻り、次回用の曲順をランダムに更新。プレイリスト編集、曲情報、再生キュー、イコライザーでは現在のハイライトを保持
- ハイライト画面から再生キューとイコライザーを直接開ける小型ボタンを表示

既知の制限：ハイライト判定は軽量なヒューリスティックであり、サビを保証するものではありません。端末上にないiCloud音源や読み取れない音源ではフォールバック候補を利用します。バックグラウンド移行中の30秒自動送りは、iOSによるタスク実行制限の影響を受ける場合があります。

### 作業用サイズ再生 — 2026-08-23

20分以上の長尺曲と、ジャンルで明示した作業用BGMを通常のランダム再生から分け、作業用の音楽としてまとめて楽しむためのベータ機能です。

- ホーム下部の「作業用」タイルから、20分以上またはジャンルが「作業用BGM」の曲をランダム順で再生
- 作業用タイルから始めた再生は、通常の再生中画面を変更せず専用の「作業用再生中」画面で表示
- 専用画面は操作がない状態で約5秒経つと暗くなり、暗転中の画面に触れると元の表示へ復帰
- 専用画面では10秒／1分単位の早戻し・早送りを利用可能
- 前の曲／次の曲はアートワークをタップしたときだけアートワーク上に表示
- プレイリスト画面の「作業用プレイリスト」から、通常用とは別に作成・名称変更・削除・並べ替え・曲追加が可能
- ホームの作業用欄は、1番目に全対象曲の再生、2〜5番目に作業用プレイリストをランダム表示し、残りがある場合は6番目の「続きを見る」から専用一覧へ移動
- 作業用プレイリストには作業用判定の曲だけ、通常プレイリストには通常曲だけを追加可能
- 作業用プレイリストの再生は専用の「作業用再生中」画面を使用
- JSON／Markdownへの書き出しと読み込みでもプレイリスト種別を維持
- 対象曲は曲リストやアルバムなどに引き続き表示し、選択して再生可能
- クイック再生、未発見再生、リピート曲再生、プレイリストのランダム再生、通常プレイヤーのシャッフル、ハイライト再生からは除外
- 既存の再生傾向による重み付けと「シャッフルから除外」の設定は専用再生でも維持
- 対象曲がない場合はホームのタイルを無効表示

既知の制限：長さの境界値と暗転までの時間は固定です。ジャンル指定は「作業用BGM」という独立したジャンル項目への完全一致で判定します。従来から保存済みのプレイリストは通常用として引き継ぎ、種別と一致しない既存の曲参照は削除せず一覧・再生対象から除外します。時間の変更設定や対象曲だけの一覧画面は未実装です。曲リストやアルバムから対象曲を直接再生した場合は、通常の再生中画面を使用します。暗転は専用画面内の表示だけを暗くし、端末の画面輝度や自動ロック設定は変更しません。

### 選択してランダム再生 — 2026-08-25

最初に聴きたい曲を自分で決め、その曲を入口に同じジャンルの音楽を続けて楽しむためのベータ機能です。

- ホームの「未発見再生」の隣にある「選択してランダム再生」から開始
- ジャンルが設定された通常曲の中から、再生傾向を反映してランダムに5曲を候補表示
- 候補を選ぶと、その曲を1曲目にして、ジャンルが1つ以上一致する曲をランダム順でキューへ追加
- 右上の「再抽選」で候補5曲を入れ替え
- 作業用サイズ再生の対象曲と「シャッフルから除外」中の曲は候補・キューから除外

既知の制限：ジャンルの一致は音源メタデータの表記に基づくため、「Rock」と「ロック」のような表記違いは別ジャンルとして扱います。ジャンル未設定の曲は候補になりません。同じジャンルの曲がない場合は、選択した1曲だけを再生します。

### 共通再生トランジション — 2026-08-22

通常再生と将来のハイライト再生で共有する、フェードイン／フェードアウト基盤です。

- 「設定」→「再生トランジション」でフェードインとフェードアウトを個別に有効化
- 0.5／1.0／1.5／2.0／3.0／5.0秒から時間を選択
- 曲の開始、自動曲送り、手動曲送りで共通の音量ランプを使用
- 設定はUserDefaultsへ保存し、アプリ再起動後も維持
- 初期状態は既存の再生感を維持するため両方オフ
- 連続操作時は古いフェードをキャンセルし、最新の再生操作を優先
- 音量制御を専用ミキサーに分離し、停止後にゲインを戻すことで切替時のクリック音を抑制
- フェードアウトがオフでも、再生ノードの停止前に約30msの安全減衰と短い無音区間を入れて波形の急断を防止
- ハイライト区間は終了時刻から逆算してフェードアウトを開始
- 「別の部分」とスワイプ切替は最大0.35秒へ短縮して操作レスポンスを優先

既知の制限：2曲を重ねるクロスフェードは未実装です。トランジション種別と手動曲送りポリシーは将来拡張用にモデル化しています。

## アーキテクチャ

```text
View
  ↓
Store
  ↓
Service
  ↓
Model / Apple Framework
```

- View：表示とユーザー操作
- Store：画面状態とServiceの接続
- Service：再生、ファイル操作、永続化、メタデータ処理
- Model：曲、アルバム、アーティスト、プレイリストなどのデータ

## 技術構成

- Swift
- SwiftUI
- Observation
- AVFoundation
- MediaPlayer
- Apple標準フレームワーク中心（外部パッケージなし）
