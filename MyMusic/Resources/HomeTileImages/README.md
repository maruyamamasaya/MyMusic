# ホームタイルのローカル画像

ホーム画面の「ライブラリ」と「アクティビティ」の背景画像を、ビルド／実機デプロイ前にローカルで差し替えるためのフォルダです。

## 使い方

1. このフォルダ（`MyMusic/Resources/HomeTileImages/`）へ画像を置きます。
2. 下表のベース名を正確に使います。拡張子は `.jpg`、`.jpeg`、`.png`、`.heic` のいずれかです。
3. Xcode で通常どおりビルドまたは実機デプロイします。

画像は Git の追跡対象外です。画像を置かないタイル、ファイル名が違うタイル、読み込めない画像は、これまでどおり既存の配色グラデーションで表示されます。

## ファイル名

| セクション | タイル | ファイル名（推奨） |
| --- | --- | --- |
| ライブラリ | 曲 | `library-songs.jpg` |
| ライブラリ | アルバム | `library-albums.jpg` |
| ライブラリ | アーティスト | `library-artists.jpg` |
| ライブラリ | ジャンル | `library-genres.jpg` |
| ライブラリ | 作曲者 | `library-composers.jpg` |
| アクティビティ | 再生分析 | `activity-analytics.jpg` |
| アクティビティ | 音楽史 | `activity-music-history.jpg` |

同じベース名で複数の拡張子を置いた場合は、`.jpg` → `.jpeg` → `.png` → `.heic` の順で最初に見つかった画像を使います。

## 画像の目安

- 正方形または縦長、1200 × 1200 px 以上を推奨します。
- タイルの比率に合わせて中央基準で切り抜かれます。
- タイトルを読みやすくするため、アプリ側で暗いグラデーションを重ねます。
- 元の配色へ戻す場合は、該当画像をこのフォルダから外して再ビルドします。
