# ホームの発掘するセクション

- Context Guard: MATCH。Git rootは指定MyMusic repositoryと一致。
- チューニング→発掘する→マイミュージックの順へ整理。既存3タイルを移動し、発掘する音楽を1つ追加。横スクロールの既存寸法を維持。
- ハイライトの固定写真をArtworkへ変更。未発見のタイル表記を短縮。残りの既存項目はマイミュージックへ維持。
- 新規選曲は現在時刻−86,400秒より前のlastPlayedAt、または履歴なしを候補として既存quickPlayTracksへ委譲。24時間境界ちょうども除外。候補0件はalert表示。
- 既存の未コミット変更を保持。データ形式・外部依存・署名設定の変更なし。
- ユーザー指示によりbuild／test／Simulator操作／deploy未実施。差分の静的確認のみ。実画面、型検証、24時間境界の実行検証は後続。
- 作成・削除したtest端末は0台。XCTest未実行、XCTestDevicesの容量調査・変更なし。

## 曲数の追加調整

- ユーザー指定でハイライトの生成上限40→100曲、クイック再生・発掘する音楽・未発見の既定上限30→60曲へ変更。ハイライト候補pool上限150、既存の選曲条件は維持。リピート曲再生は変更なし。
- git diff --checkで差分の空白エラーなし。build・test・deployは指定により未実施。テスト端末作成・削除0台、XCTestDevices変更なし。
