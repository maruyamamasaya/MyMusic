# 再生中 Visual World — Beta 設計

## 目的

現行の標準再生中画面を残し、選択中のテーマと曲のジャケットに由来する「アート画面」を同じシート内に追加する。右上の「完了」は両画面の切り替えボタンへ置き換える。音源、キュー、再生履歴、既存の再生機能と設定の意味は変えない。作業用再生画面は別画面として維持する。

## 画面

- 全面は黒を基調とし、現在の `AppTheme` の光の方向と形を引き継ぐ。ジャケットから抽出した色は低輝度の拡散光に用い、テーマのアクセントを混ぜる。シンプルダークも黒い余白を残した控えめな光にする。
- 曲の `energy`、`calm`、`ambient`、`bright`、`tempo` がある場合、光の密度、速度、広がりを決める。欠損値は中立値とし、解析済みであるかのような表示をしない。
- 再生中の出力タップから取得するレベルは光の明滅に用いる。ステレオの左右差は光の重心、左右チャンネルの差分は横方向の広がりに用いる。モノラルまたは取得不能時は中央寄せにする。これらは表示専用で、音声の処理やファイル形式を変更しない。
- 常時表示する情報は左側の小さなジャケット、曲名、アーティスト名に絞る。文字は暗い面で保護し、Dynamic Typeで欠けないようにする。
- 現行画面では右上に「アート画面へ」の切り替えボタンを置く。アート画面では同じ位置に「通常画面へ」の細いアイコンを低い視覚強度で置く。どちらもVoiceOverには明示名を付ける。シートの下方向スワイプで閉じる。

## 操作

| 入力 | 動作 |
| --- | --- |
| 背景を1回タップ | 再生／一時停止 |
| 背景をダブルタップ | お気に入り切替。対象外の曲では変更しない |
| 背景を右へスワイプ | 次の曲 |
| 背景を左へスワイプ | 前の曲。既存の「再生位置が3秒以上なら曲頭へ戻る」規則を維持 |
| 背景を長押し | 再生位置と操作パネルを表示 |
| 長押し後の横移動 | 再生位置のプレビュー。指を離した時にseek |

長押しパネルには既存の前／再生／次、shuffle、repeat、Good／Bad、飽きた、あとで聴く、プレイリスト追加、キュー、EQ、オーディオ情報、曲別調整を残す。シーク用Sliderも提供し、VoiceOverなどの代替操作とする。パネル上の操作は背景gestureから分離する。

## 所有とデータフロー

`AudioPlayerService` の既存タップで出力レベルとステレオ幅を計算し、`PlayerStore` に表示専用の値を渡す。`TrackFeatureStore` は既存のインポート値だけを提供する。ジャケット読み込みと小画像での代表色計算、テーマとの合成、アニメーションは再生画面の専用Viewへ閉じ込める。永続化、JSON、Watch通信に値を追加しない。

## 描画とアクセシビリティ

再生画面が前面かつ再生中の間だけ低頻度で光を更新する。波形の各サンプルを直接描かず、平滑化したレベルを数層のグラデーションへ反映する。画面を閉じたら描画負荷を止める。Reduce Motion、透明度低減、コントラスト増加では静的な低輝度表現にする。操作はVoiceOverから明示的なラベルとボタンでも実行できる。

## Beta 検証

４テーマ、ジャケットあり／なし、特徴量あり／なし、モノラル／ステレオ、一時停止、曲切替、長押しとスワイプの競合、シートの閉じ方を確認する。Swift buildと既存の再生フローの回帰確認後、実機で光量、発熱、操作認識を調整する。
