# Visual World — Photon Sphere

## 方向変更

幾何学の枠・模様を撤回し、主役を「光でできた立体的な球体ひとつ」に統一する。量子的な印象は、内部の光の密度・流れ・確率的な明滅で表す。物理的に正確な光子／量子シミュレーションを目的にはしない。

## 実装

- 球体は画面短辺の約90%（固定サイズ）、中心は高さ43%付近。前後の厚み、方向のある光、吸収、表面highlightで立体感を作る。
- 球の内部を最大18 step（低品質10）でsample。連続した3Dの密度場、細い発光、局所的な光の粒子を合成する。外側には同じ球由来の柔らかいhaloのみ。
- 体積の音連動は撤廃。中域と24帯域は内部の発光、高域は粒子の励起、音程感は内部光の密度へ接続。慣性と回転で音が止まった後も有限の余韻を残す。
- Simple Dark／Living Auroraは球体ひとつを保つ。色はArtwork／既存theme fallbackから取得する。
- 2026-09-17追加：Blue Cosmosは青い夜空へ分岐。最大3層（低品質2層）の星、淡い星雲、緩い視差、音域に応じた輝きと明滅を使用。Canvasにも星空fallbackを用意。球体のテーマには影響しない。
- Metal不可時のCanvasも単一球体と粒子へ変更。枠や軌道の旧描画へ戻さない。
- 音声解析・再生機能・コントローラー操作・低電力／熱制御は変更しない。

## 確認

Simulator向けbuild成功、Mac GPUで実shaderを描画し立体感を目視。iPhone実機の見え方・長時間の熱評価は未実施。今回の変更は描画のみで、追加のXCTestは実行していない。

## 2026-09-17 ライティング／Pulse Neon

- 球体の膨張・収縮を撤廃し、回転も音の衝撃で揺らさない。内部粒子の方式は維持する。
- 球体外側のhaloを拡張。Artwork主色→副色の方向性のあるgradientへaccentを少量混ぜ、中域で光量だけを穏やかに変える。
- Pulse Neonは別描画。左右の蛍光チューブがX字に交差し、上下の光と合わせて中央の通路を囲む。奥のゲートが手前へ拡大し、通り抜けるワープ感を作る。通常10／低品質6ゲート。色はArtwork、発光は音域に応答。
- Canvas fallbackも固定球体＋拡散光／交差ゲートに対応。Blue Cosmosの夜空、再生操作・解析は変更なし。
- 変更後のSimulator build成功。Mac GPUで球体とゲートの実shaderを目視確認。追加XCTest・実機確認は未実施。

## Blue Cosmosの星の調整

- 星のcoreを描画target上で約0.45〜0.80pxへ縮小し、haloの幅と強度も低減。
- 位置・大きさ・色・発光タイプのseedを分離。常時点灯45%、緩い瞬き35%、星ごとに異なる位相のパルス20%とする。常時点灯は音量に連動しない。
- 主色／副色の配分にArtworkの占有率を使用し、少数のaccent・白い星も混ぜる。青／赤の温度差を28%混ぜ、ジャケット色を主体にする。
- パルスは滑らかに立ち上がり、ゆっくり減衰。画面全体が同時に点滅しない。Canvas fallbackも小さい点・3種の輝き・Artwork配色へ変更。
- Simulator buildとMac GPU描画確認済み。実機未確認。今回XCTestは未実行。

## 星の動きが気づきにくい問題への調整

ユーザー確認では非表示ではなく明滅の変化不足。最小サイズを上げる試行は撤回し、従来の小さいcoreを維持した。常時点灯45%は固定、瞬く35%の明暗差を拡大し、パルス20%の立ち上がり・減衰を目立たせる。パルスの周期を短くし、ピーク時のみhaloと白い芯を追加。位相は星ごとに異なり、全画面の一斉点滅にはしない。Canvasも同じ方針。

## 星のサイズのばらつき

小さい星を中心に、サイズ用seedの上位約18%へ滑らかな加算を行う。Metalのcore半径は最大約1.65 render px、Canvasは最大約1.47pt。明滅タイプとサイズは独立したseedなので、大きな常時点灯星もパルス星も存在する。配色と明滅の強度は維持する。

## 星の緩やかな座標移動

既存の全体driftに、星ごとに速度と位相が異なる小さな楕円状の漂流を追加。奥ほど遅く小さく、手前ほどやや速く大きく動く。元のcell／seedを固定し、移動しても色・サイズ・明滅タイプを再抽選しない。追加のtimerは使わず既存描画clockに従い、休止・Reduce Motion時は停止する。Metal／Canvas双方に反映。
