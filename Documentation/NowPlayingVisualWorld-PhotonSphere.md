# Photon Sphere（現行造形）

再生中のビジュアル全体の操作・入力・休止条件は[現行仕様](NowPlayingVisualWorld.md)を参照する。この文書はPhoton Sphere固有の造形を記す。

- 主役は画面短辺の約90%を占める固定外形の球体。高さ43%付近に置き、方向のある照明、吸収、表面highlight、外側のhaloで厚みを作る。音量で球体を膨張・収縮させない。
- Metalは内部の密度場と粒子を通常18 step、低品質10 stepで有界にsampleする。中域と24帯域は内部の発光、高域は粒子、音程感は内部光の密度に作用する。
- 外側には軌道線を描かず、曲ごとのseedで動く最大16の微小光子と3つの衛星球を置く。低品質では9光子と2衛星。複数周期を重ねた連続軌道で動かし、明滅も粒子ごとにずらす。
- Artworkの主色・副色・accentを内部光と方向性のあるhaloに使う。Canvas fallbackも固定球体、内部粒子、外周の光子と衛星球を描く。ただし体積描画の奥行きはMetal固有である。

枠・膜・弧の旧案と、その後の球体・星・ゲートの調整経緯は[Beta 3の履歴](NowPlayingVisualWorld-Beta3.md)と`sessions/2026-09-16-*`、`sessions/2026-09-17-*`に残す。iPhoneでの6種類の連続鑑賞と熱・電力の評価は未完了。
