# 再生中のビジュアル：作品レビュー（2026-09-19）

対象は現行の6種類。以下は[実装](../MyMusic/Views/Player/VisualWorldInstallation.metal)と[Canvas fallback](../MyMusic/Views/Player/VisualWorldScene.swift)、既存の検証記録から読める**構成上の評価**であり、6種類を同じ曲・端末・時間で見比べた実機の最終評価ではない。名称・選択ID・操作・描画条件は[現行仕様](NowPlayingVisualWorld.md)を正とする。

## 全体像

全種類が同じ再生画面、Artwork配色、表示専用の音声解析、最大30fpsと熱・アクセシビリティ制御を共有する。差が出るのは、その入力を何に変換し、画面内にどの程度の奥行きや変化を作るかである。Photon SphereとBlue Cosmosは主役、周辺、時間変化の関係が特に明確。他の4種類も実装済みだが、長く眺めたときの展開と独自性は実機で比較する余地がある。

| 作品 | 現在の核 | 構成上の強み | 次に見るべき点 |
| --- | --- | --- | --- |
| Photon Sphere | 固定外形の球と内部の発光、外周の微小光子・衛星 | 陰影、吸収、体積、内外の速度差が一つの物体を成立させる | 曲による内部光の違いが見えるか。Canvas時の奥行きの差 |
| Blue Cosmos | 星雲と最大3層の星空 | 星ごとにサイズ・色・明滅・漂流が異なり、遠景にも時間がある | 曲ごとの変化が過剰な一斉点滅なしに伝わるか |
| Pulse Neon | 5形から選ぶ光のゲートが手前へ進む | 遠近と通過の方向が明快。形は奥で消えた時に更新 | 繰り返すゲート以外の展開や、曲の個性が感じられるか |
| 薄明 | 青い空、少ない星、雲、暖色の地平線 | 明暗と色温度の対比があり、Cosmosとは静けさが違う | 星空の密度を下げた派生に留まらず、雲・地平線を主役として読めるか |
| Plasma Spark | 蛇行する3本の電流、走る電荷、火花 | 光の流路と高速の局所運動がある | 3本の並走と定常的な火花が反復に見えないか。静かな曲との関係 |
| Visualizer | 48点波形、24帯域バー、粒子 | 音との対応が最も直接的で、情報の読みやすさがある | バーが主役の計測表示から、鑑賞する作品としてどう発展させるか |

## 優先して比較すること

1. **同一条件で鑑賞する。** 同じ3曲（静穏、リズム主体、音色が大きく変わる曲）、Artworkあり／なしで6種類を各1〜3分見る。静止画だけで判断しない。SphereとCosmosを基準に、無音付近・強い区間・曲切り替えの3場面で視線の行き先を記録する。
2. **Pulse NeonとPlasma Sparkの反復を観察する。** ゲートの形や電流の位置が変わることと、作品として展開が生まれることは別。曲の入力が輝度だけでなく構図の強弱を作れているかを判断する。
3. **薄明とVisualizerの役割を決める。** 薄明はCosmosとの差を雲・地平線の時間変化で、Visualizerは正確な音の読み取りと作品性の両立で評価する。名前やエフェクト数を増やす前に、各作品で最も記憶に残る瞬間を一つ定義する。
4. **MetalとCanvasを別々に確認する。** Canvasは初期化失敗時のfallbackであり、Sphereの体積やCosmosの星雲を同等には再現しない。作品品質を判断する際はどちらで描画したか記録する。

現時点では6種類を削除・統合する根拠はない。選択IDは保存・バックアップにも使うため、作品の取捨選択は実機比較後に決める。古い造形資料は履歴として明示し、現在の作業では[Photon Sphereの説明](NowPlayingVisualWorld-PhotonSphere.md)を現行造形だけへ縮約した。
