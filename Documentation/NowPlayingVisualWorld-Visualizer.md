# Visual World — Visualizer

画面中央を左右に横切る一本の波形を主役にする。48点のPCM波形に低・中・高域それぞれ異なる周期と振幅の揺れを加え、白い芯と淡い色の光で描く。設定 → デザイン → 再生中のビジュアル、またはアート画面のメニューから選ぶ。選択IDは `visualizer`。

## 音と見た目

- 低域は大きくゆっくり、中域は細かくうねり、高域は短く鋭い揺れになる。優勢な音域で光の色が変わる。
- Beatに反応して中央から円形の薄い波紋を一度だけ広げ、0.8秒以内に消す。
- 微小光子はPhoton Sphereと同じ描画関数、数、軌道を使う。
- 余分なスペクトラムバー、フィラメント、独立した粒子バーストは描かない。
- 解析値は表示専用であり、音声処理・再生・保存データへ戻さない。Metal初期化不能時はCanvas fallbackを使う。

Canvasの静穏・低域・中域・高域画像で一本線の形と余計な光がないことを確認する。iPhone実機のMetal描画と長時間の熱・電力は未確認。
