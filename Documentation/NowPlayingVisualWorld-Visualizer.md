# Visual World — Visualizer

Waveformを強い発光を持つ奥の主役、24バンドのSpectrumを手前の音の輪郭、微小光子を二つの層をつなぐ前景として描く。設定 → デザイン → 再生中のビジュアル、またはアート画面のメニューから選ぶ。選択IDは `visualizer`。

## 音と見た目

- 既存の2048点FFTから低・中・高域と24バンドを取得する。Spectrumは画面下の独立した棒列ではなく、全幅波形上の24地点から上下交互に噴き出すフィラメントとして描く。低域は太く長く、中域は横へ揺れ、高域は細く短い。音が弱いときは輝度を抑え、発生源と頂点にだけ光を残す。
- Waveformは同じPCM窓を48区間に分け、左右で振幅が大きい方の符号付きピークを取る。左右の画面端を結ぶ主軸として、白い芯、色の膜、広い光、薄い余韻を重ねる。音圧に応じて振幅・線幅・明度を変える。音を再加工せず、解析キューから表示専用の値として渡す。
- Beatはスペクトルの正の変化量（flux）を緩い基準値と比較し、短い残光にする。音声経路への制御はしない。
- 波紋は音域と発生回数から8種を選ぶ。低域は真円・楕円・画面端からの波、中域は干渉・液体波・歪曲、高域は断片波・放射状の光に分かれる。1回の発生中は形を保持し、0.9秒以内に消える。
- 微小フォトンは曲ごとのseedで個別の位置・速度・色を持つ。低域の大きな自由粒子、中域の波形に沿う流れ、高域の小さく速い光へ分ける。全画面を流れる速度に緩い変調を加え、波形への引力と横向きの偏向で軌道を曲げる。アタックでは周波数群別に散乱させ、指数減衰で元の流れへ戻す。毎frame再抽選せず、低品質では密度を下げる。
- beat検出時には低・中・高域の強さを記録し、最大0.95秒の粒子バーストを発生させる。全幅の波形と帯域、左右端、画面下部を発生点にする。低域は大きな粒子、中域は流れ、高域は細かな高速粒子を担う。発生点と方向は曲seedと発生回数で安定させる。
- burstは表示用Simulationだけの状態であり、再生・音声解析・保存データへは戻さない。Metalは通常24粒子、低品質12粒子、Canvasは最大24粒子に制限する。前面・Reduce Motion・低電力・thermal状態の既存制御とMetal不能時のCanvas fallbackを共有する。

同じ曲でSphereと交互に見て、波形の芯がSpectrumを埋めないか、微小光子が点滅のノイズにならないか、静かな区間から強い区間への変化と粒子の飛散が明確かを評価する。iPhone実機での長時間の熱・電力と視認性は未確認。
