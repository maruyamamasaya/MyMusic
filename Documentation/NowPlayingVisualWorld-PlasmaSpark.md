# Visual World — Plasma Spark

## 造形

暗い空間で、音のピークごとに一本の稲妻状の放電が現れる。20個の固定テンプレートは左右・上下・対角の端から反対側の端まで届き、それぞれ異なる折れ方を持つ。曲seedを起点に放電回数で20種類を巡回し、中域の強さで折れ幅だけを少し変える。白熱した芯の周囲に紫・シアン・ローズの電離光を重ねる。

放電は約0.052秒で経路を走り、強い閃光の後すぐに減衰する。残光と散った電荷も0.43秒以内に消す。音のピークがない時は暗い空間だけを描き、常時点灯する電流や火花は置かない。

## 音との連動

- 低域が優勢なピークは太い放電と短い背景フラッシュ。
- 中域が優勢なピークは折れ幅を増やして蛇行を強める。
- 高域が優勢なピークは細い放電、短い枝分かれ、速い減衰。
- 全音域で主線は端から端まで届く。経路の周囲へ少数の電荷粒子を散らす。Metalは通常6粒子、低品質3粒子、Canvasは6粒子に制限する。

既存の音声解析が出すflux／低・中・高域から、表示専用Simulationがピーク時刻と強度を記録する。MetalとCanvas fallbackはこの値を共有する。音声処理・再生・設定ID・永続化は変更しない。前面表示、アクセシビリティ、低電力・thermal状態による既存の描画制御を共有する。
