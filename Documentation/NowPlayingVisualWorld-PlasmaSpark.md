# Visual World — Plasma Spark

## 造形

暗い空間を3本のプラズマ電流が縦に横断する。紫、シアン、ローズの流れが独立して蛇行し、幅の広い淡い発光、細い高温の芯、電流から分岐して戻る放電を重ねる。白い電荷が線上を走り、細かな火花が周囲へ流れる。光量だけの変化ではなく、流路・電荷・火花それぞれの位置が継続的に変わる。

参照画像の空間を満たす光と複数の色の気配を踏まえ、従来の固定格子と虹色の短い線分は廃止する。画像アセットは取り込まず、独自の描画で構成する。

## 実装

- Metalは3本（低品質では2本）の解析的な流路、各流路に沿って走る電荷、短命な火花を有界の計算で描く。音域と短期の励起は輝度に作用し、無音時も流れの運動を維持する。
- Canvas fallbackも同じ流路・走る電荷・火花を描く。描画は表示専用で、音声処理・JSON・永続化は変更しない。
- 前面表示と再生状態、アクセシビリティ、低電力・thermal状態による既存の描画制御を共有する。
